# 🏛️ 고대 이집트 상형문자 학습 프로그램

고대 이집트의 신비로운 상형문자를 학습하는 대화형 교육 프로그램입니다. 

## 📋 프로젝트 개요

이 프로젝트는 사용자들이 고대 이집트 상형문자를 체계적으로 학습할 수 있도록 설계된 웹 애플리케이션입니다. 다양한 학습 도구와 게임화된 퀴즈를 통해 효과적인 학습을 지원합니다.

### ✨ 주요 기능

- **📚 학습**: 이집트 상형문자의 의미, 발음, 역사적 배경을 카드 형식으로 학습
- **🔊 음성 발음**: Web Speech API를 사용한 한국어 음성 발음 재생
- **🎮 퀴즈**: 객관식 퀴즈를 통해 학습 내용을 확인하고 정답률을 추적
- **📊 진행률 추적**: 학습한 글자 수, 퀴즈 정답률, 총 점수 표시
- **🔍 카테고리 필터**: 동물, 신체, 건축, 도구, 음식, 개념별로 글자 분류
- **⭐ 난이도 선택**: 초급, 중급, 고급 난이도로 학습 커스터마이징
- **👤 프로필 페이지**: 상세한 학습 통계, 난이도별/카테고리별 진행률 확인
- **🏅 배지 시스템**: 8가지 배지를 획득하며 학습 동기 부여
- **🔥 스트릭 추적**: 연속 정답 기록으로 학습 집중도 측정
- **💾 자동 저장**: 브라우저의 로컬 스토리지에 사용자 진행 상황 자동 저장

## 🚀 시작하기

### 전제 조건
- 웹 브라우저 (Chrome, Firefox, Safari, Edge 등)
- Python 3 (로컬 서버 실행용, 선택사항)

### 설치 및 실행

#### 방법 1: 로컬 서버 실행 (권장)

```bash
# 프로젝트 디렉토리로 이동
cd ANCIENT_EGYPT_LANGUAGE_WORD_261002

# Python HTTP 서버 시작 (포트 8000)
python3 -m http.server 8000

# 브라우저에서 열기
# http://localhost:8000/src/index.html
```

#### 방법 2: 직접 파일 열기

2. 프로그램이 시작됩니다

> ⚠️ **주의**: 데이터 로딩에 문제가 있을 수 있으므로 로컬 서버 실행 방법을 권장합니다.

## 📖 사용 방법

### 1️⃣ 학습 탭 (📚)
- 이집트 상형문자 카드를 클릭하여 글자 학습
- 각 카드의 🔊 버튼을 클릭하여 발음을 음성으로 들을 수 있음
  * 재생 중: 버튼이 빨강색(🔴)이 되고 펄스 애니메이션 표시
  * 재생 중 버튼 클릭: 음성 정지
  * 음성 내용: "글자명. 발음: [발음기호]" (한국어)
- 카테고리 필터를 사용하여 특정 유형의 글자만 표시
- 카드를 클릭하면 "✓ 학습함"으로 표시됨

### 2️⃣ 퀴즈 탭 (🎮)
- 무작위로 선택된 10개의 글자로 퀴즈 시작
- 글자의 의미를 4개 선택지에서 고르기
- 정답/오답을 시각적으로 표시하고 2초 후 자동으로 다음 문제로 진행
- 퀴즈 완료 후 정답률과 획득 점수 확인
- 퀴즈 완료 후 배지 조건 자동 확인

### 3️⃣ 진행률 탭 (📊)

**통계 카드**:
- **학습한 글자**: 학습 완료한 글자 수 / 전체 글자 수
- **퀴즈 정답률**: 퀴즈에서 맞춘 문제의 백분율
- **총 점수**: 정답 1개당 10점

**인터랙티브 차트 대시보드** (5단계-2 추가):
- 📈 **퀴즈 시도 추이**: 최근 20개 퀴즈의 누적 정답 수를 라인 그래프로 표시
- 🥧 **카테고리별 학습 비율**: 6개 카테고리별 학습 현황을 도넛 차트로 시각화
- 📊 **난이도별 완성도**: 초급/중급/고급별 완성도(%)를 막대 그래프로 표시
- 차트는 탭 클릭 시 자동으로 최신 데이터로 업데이트됨

### 4️⃣ 프로필 탭 (👤)
**사용자 정보 카드**:
- 총 학습 글자: 학습한 글자 수
- 퀴즈 정답: 정답한 문제 수
- 퀴즈 시도: 풀어본 퀴즈 총 횟수
- 누적 점수: 모든 퀴즈에서 얻은 점수

**난이도별 학습 현황**:
- 초급 진행률 (0~10개)
- 중급 진행률 (0~10개)
- 고급 진행률 (0~10개)
- 프로그레스 바와 달성도 표시

**카테고리별 학습 현황**:
- 동물, 신체, 건축, 도구, 음식, 개념별 진행 상황
- 각 카테고리별 학습한 글자 수 / 전체 수

**연속 정답 (스트릭)**:
- 🔥 현재 스트릭: 최근 연속 정답 수
- 🔥 최고 스트릭: 지금까지의 최고 기록

**획득한 배지**:
- 8가지 배지 중 조건을 달성한 배지만 금색으로 표시
- 미획득 배지는 회색으로 표시되며 조건을 보여줌
- 배지 호버 시 확대 효과

## 💾 데이터 저장

사용자의 학습 진행 상황은 브라우저의 **로컬 스토리지**에 자동으로 저장됩니다.

저장되는 데이터:
```json
{
  "userProgress": {
    "learnedHieroglyphs": [1, 2, 3],
    "quizAttempts": [
      {
        "hieroglyphId": 1,
        "selected": 1,
        "correct": true,
        "timestamp": "2024-10-02T12:34:56.789Z"
      }
    ],
    "totalScore": 50,
    "lastUpdated": "2024-10-02T12:34:56.789Z"
  }
}
```

### 진행 상황 초기화

브라우저 개발자 도구(F12)의 콘솔에서 다음 명령어를 실행:
```javascript
resetAllProgress();
```

|------|------|------|------|

- **현재 스트릭**: 최근 연속 정답 수
- **최고 스트릭**: 지금까지의 최고 연속 정답 수
- 오답 시 현재 스트릭 초기화 (최고 기록은 유지)

## 🔊 5단계 - 음성 발음 기능

### 기능 설명
각 글자 카드에 🔊 버튼을 추가하여 발음을 음성으로 들을 수 있습니다.

### 사용 방법
1. 학습 탭에서 글자 카드의 🔊 버튼 클릭
2. 음성 합성을 통해 "글자명. 발음: [발음기호]" 형태로 재생
3. 재생 중에 다시 클릭하면 정지
4. 버튼 색상으로 재생 상태 확인:
   - 🔊 회색: 준비 상태
   - 🔊 빨강색 (펄스 애니메이션): 재생 중

### 기술 사양
- **API**: Web Speech API (SpeechSynthesis)
- **언어**: 한국어 (ko-KR)
- **음성 설정**:
  - 재생 속도: 0.9배 (천천히 들을 수 있도록)
  - 음정: 1.0 (기본)
  - 음량: 1.0 (최대)

### 구현 함수
**utils.js**:
```javascript
speakGlyph(glyph, onStart, onEnd)  // 글자 발음 재생
stopSpeech()                        // 음성 재생 정지
```

### 브라우저 호환성
- ✅ Chrome (모든 버전)
- ✅ Firefox (모든 버전)
- ✅ Safari (iOS 14+, macOS 10.15+)
- ✅ Edge (모든 버전)
- ⚠️ 지원하지 않는 브라우저: 경고 메시지 표시

## 📊 5단계-2 - 통계 대시보드

### 기능 설명
진행률 탭을 인터랙티브한 시각적 대시보드로 개선하여 학습 진행도를 다각도로 분석합니다.

### 차트 종류 및 데이터

#### 1️⃣ 📈 퀴즈 시도 추이 (Line Chart)
**표시 내용**: 최근 20개 퀴즈의 누적 정답 수

**특징**:
- 시간에 따른 성장 트렌드 시각화
- 정답할 때마다 라인이 위로 올라가는 형태
- 점프 표시로 각 퀴즈 위치 표시
- 학습 동기 부여 효과

**색상**: 갈색 선 (#8B4513), 투명한 배경

#### 2️⃣ 🥧 카테고리별 학습 비율 (Doughnut Chart)
**표시 내용**: 6개 카테고리별 학습한 글자 수

**카테고리별 색상**:
| 카테고리 | 색상 | RGB |
|---------|------|-----|
| 동물 | 빨강 | #FF6B6B |
| 신체 | 청록 | #4ECDC4 |
| 건축 | 파랑 | #45B7D1 |
| 도구 | 라이트 연어 | #FFA07A |
| 음식 | 민트 | #98D8C8 |
| 개념 | 노랑 | #F7DC6F |

**특징**:
- 한눈에 균형잡힌 학습 여부 파악
- 어느 카테고리가 약한지 시각적으로 파악
- 범례로 각 카테고리 확인

#### 3️⃣ 📊 난이도별 완성도 (Bar Chart)
**표시 내용**: 초급/중급/고급별 완성도(0~100%)

**난이도별 색상**:
| 난이도 | 색상 | 설명 |
|-------|------|------|
| 초급 | 연두 (#90EE90) | 완성도 초기 단계 |
| 중급 | 금색 (#FFD700) | 중간 진행도 |
| 고급 | 빨강 (#FF6B6B) | 최고 난이도 |

**특징**:
- 0~100% 스케일로 완성도 표시
- 막대 길이로 진행도 직관적 파악
- 각 난이도별 목표 달성 현황 한눈에 확인

### 사용 방법
1. 진행률 탭(📊) 클릭
2. 기존 통계 카드 확인 (상단)
3. 아래로 스크롤하여 3개의 차트 확인
4. 차트는 자동으로 최신 데이터 반영

### 기술 스택
- **라이브러리**: Chart.js 4.4.1
- **소스**: CDN (cdn.jsdelivr.net)
- **캔버스**: HTML5 Canvas API
- **데이터**: localStorage의 사용자 진행도

### 반응형 디자인
- **데스크톱** (768px+): 3열 그리드
- **태블릿** (480~768px): 2열 그리드
- **모바일** (~480px): 1열 레이아웃
- 모든 기기에서 최적의 가독성 제공

### 실시간 업데이트
- 진행률 탭 클릭 시 자동으로 차트 렌더링
- 새로운 퀴즈 완료 후 탭 이동 시 최신 데이터 표시
- 글자 학습 후 탭 이동 시 카테고리 데이터 갱신
